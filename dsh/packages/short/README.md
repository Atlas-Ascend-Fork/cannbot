# CANNBot DSH

`cannbot-dsh@1.0.0-alpha.5` 是 `@cannbot-plugin/cannbot-dsh@1.0.0-alpha.5` 的短包名入口，为昇腾 / CANN 项目提供开发工作台，作为插件运行在 DSH 宿主中。

在 **插件 → 添加插件** 中输入 `cannbot-dsh@1.0.0-alpha.5`。新版本受安装源同步及发布时间观察期影响时，请明确指定版本号。
Linux 也可执行：

```sh
dsh plugin --profile web add cannbot-dsh@1.0.0-alpha.5
dsh web
```

安装时通过标准 npm 依赖一次装齐 3 个默认工作流包，目前加载 53 个 Skills；依赖下载失败会让安装阶段报错。首次启用等待本地资源准备完成，不会在后台补装子包。每个 `@cannbot-plugin/workflow-<ID>` 可独立更新和回退，无需升级主程序。目录包 `@cannbot-plugin/workflow-catalog` 用于发现新工作流。

当前源码的主插件提供面向昇腾 / CANN 的开发工作台和 DSH 内嵌远端连接。CANNBot 模式使用 CANNBot 品牌，“插件 / 自动化任务 / 更多”列表上方显示通用左箭头和“返回原生工作台”，点击恢复宿主原有界面。当前为 DeepSeek Harness 时，点击“插件”上方的 CANNBot 入口，再选择本机工作区，或连接服务器后展开它的工作区和会话。服务器按原生项目层级显示连接状态，单独展开未连接服务器不会自动连接。创建 CANNBot 工作区要求空目录；工作流默认留空且必须手动选择；“空白昇腾工作区”不预装工作流，供手动配置昇腾项目，也可选择一种固定工作流初始化。准备好工作区后直接打开 DSH 原生空会话，保留模型、权限和附件控件，不自动发送。DSH 原生列表可显示全部会话，CANNBot 侧只显示从 CANNBot 启动并登记的会话，普通历史会话不会自动加入。准备失败可重试，已有原生草稿和文件保留。

DeepSeek 模式使用原生侧栏列表、工作区下拉、主页、主会话区和底部工具栏，搜索、添加及快捷键由 DSH 处理。CANNBot 列表不添加搜索框；选中行以 DSH 同款背景高亮，文字颜色保持不变。CANNBot 启动页标题为“现在，交给CANNBot”，只提供工作区下拉框及只读的绑定工作流信息；工作流仅在创建工作区时选择，启动页不提供工作流下拉框，品牌旁不显示 Preview 标签。服务器状态使用中性图标及提示，展开未连接行不会自动发起 SSH。

服务器连接图标在悬停或键盘聚焦时显示，已连接后点击即可断开本机 SSH 隧道，远端 DSH 和任务保留。首次工作区读取显示加载状态并自动重试暂时失败的读取，持续失败后才显示错误；连接及读取重试不会重复提交工作区修改。

Windows 桌面端可通过 SSH 在 DSH 内打开远端工作区与会话，默认可同步受支持的本机 DeepSeek 平台登录，保留已有远端登录。Windows 一键安装请下载并双击 [CANNBot-Setup.exe](../../CANNBot-Setup.exe)，见 [主说明](../../README.md)；本短包入口使用其精确依赖的已发布主包，不会读取本地未发布改动。

当前源码的本机及远端侧栏按原生位置显示工作区 **⋯、新会话** 和会话 **⋯、归档、置顶** 操作，支持重命名、删除工作区、分叉会话及复制 Session ID。删除工作区保留文件和历史会话，原会话显示在“未分组”；顶部 **视图选项** 可筛选已归档会话并恢复。服务器菜单支持编辑备注，清空备注恢复 SSH 别名。

插件详情提供逐项更新、回退、检查版本和更新全部。回退版本会固定，主动更新该项即可恢复跟随最新版。主程序自己的“检查更新”和一键升级保留。

选择工作流创建工作区时，Host 自动调用包内保留的上游 DSH 安装器准备所选工作流；相同工作区和包版本不重复初始化。一个目录不能混用两个 CANNBot 工作流，失败后可以原目录、原工作流重试。依赖仓库仍按上游声明获取，某些工作流首次准备需要 Git、网络及其运行条件。输入框不出现 `/工作流名称`，发送时在后台应用工作流。

首次下载需要网络；已安装工作流可离线加载。支持 Windows 桌面与 Linux Web，Node.js >=24.9，DSH >=0.1.1-rc.1 <0.3.0；图形管理依赖对应官方接口。桌面内嵌远端页面要求 DSH 的原生浏览器服务；切换工作模式不删除工作流或历史数据。
