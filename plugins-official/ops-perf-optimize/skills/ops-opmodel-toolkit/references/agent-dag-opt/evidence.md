# 候选结果与使用限制

输入为同一实验的基线、候选、case、硬件、成本和输出报告。
只有评价后端、数学语义、输入与范围一致的结果才能比较。

交付每个候选的模型目录、有效参数、任务量、周期、成本来源、验证状态和复现命令。
分别报告已完成评价、失败、预算未覆盖和仅登记的候选；固定点不算参数空间搜索。
`scored` 不自动表示数值通过、成本已校准或已取得设备收益。

VF 实测、系数/公式及可选预测按[VF 接口](../framework/vf-costs.md)记录身份。
预测排名、已验收排名和 recommendation 按实际字段分别说明，不由代理自行提升资格。
候选采用后，重新加载导出模型并运行原 case；数值与设备验收另行记录。

用[会话命令](../framework/graph-search.md)保存真实结束原因。
预算耗尽、暂停或没有新实验不表示全局最优；保留未尝试方向与失败输入。
更换成本、硬件、包版本或候选文件后重新评价，不混用历史结果。
