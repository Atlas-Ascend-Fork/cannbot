# 硬件与成本输入

使用 `operator.yaml:hardware` 选择安装包中的 profile，或将 YAML 复制到用户项目后修改。
导出及覆盖命令见[硬件配置](../hardware.md)。不同模型入口对 `--hardware` 的支持不同，
以[CLI](../cli.md)和调用帮助为准。

## 输入含义

- 时钟用于周期与时间的换算；容量、核数和 AIV 配比必须对应目标 profile。
- 搬运路由使用 `src/dst/pipe/bw`，可选 `bw_tiers`；单位按 profile 约定填写。
- `t_up/t_down` 是不接受的旧字段，应删除键而非设为零。
- 张量 dtype、形状、实际搬运量和缓冲区容量由模型声明，不能靠修改带宽掩盖数量错误。
- 已预切分到单 AIV 的工作量使用相应的 `aiv_presplit` 声明，避免重复分摊。
- `pipeline_execution` 等可选配置只用于版本支持的模型组合；配置值须有来源和适用范围。

没有独立依据时保留现有 profile，并在结果中注明假设。合成配置、理论参数、
拟合参数和设备规格分别记录；增加一个参数不证明该硬件行为已被测量。

## 输出和限制

记录本次有效 profile、版本/摘要、时钟、覆盖项及成本来源，核对结果中的身份。
硬件变更后重跑基线与候选，不混用旧评分。
显式选择 L2 档位表示输入假设，不能单独证明设备缓存命中。
容量检查通过不替代实际编译布局或设备运行验证。
