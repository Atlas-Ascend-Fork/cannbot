# 定制能力

| 目录 | 职责 | 不包含 |
|---|---|---|
| requirement/ | 按平台对齐需求，确定语言、目标与授权 | workflow 调度 |
| env-check/ | 平台与语言组合的环境检查 | 自动安装、工程生成 |
| repo-guide/ | 仓库编码、测试与交付约定 | 工具链环境检查 |
| engineering/ | 工程骨架、构建和实际测试接入 | 需求决策与独立验收 |
| doc-templates/ | 报告格式与证据表达 | 新增验收门槛 |

仅链接选中的末级实现；同能力同名变体不能同时注册。共用资料随完整资产树提供，不作为独立 Skill 安装。
