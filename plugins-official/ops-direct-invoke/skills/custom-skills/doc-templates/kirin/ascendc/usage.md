# 报告模板使用

模板只规定证据的表达方式，不增加任务、改变验收门槛或复制原始日志。按当前 task 选取所需模板；不用的栏目标明不适用，不能因模板有某一栏声称已经执行。

`$DOC_TEMPLATES_DIR/templates/` 指向本轮选定实现内独立维护的模板。安装和冻结须保留本实现的完整说明与模板文件。

报告按完整节点 ID 和尝试号保存在 task 指定位置，引用绝对证据路径。区分执行者记录与验收者结论、设备与 Simulator、正常/异常/跳过/未执行、局部与全量；结果须对应最终代码、测试、构建与加载身份。

| 内容 | 模板 |
|---|---|
| 资料与实现草稿 | [知识搜集](templates/知识搜集.md) |
| 规格覆盖 | [黑盒测试设计](templates/黑盒测试设计.md) |
| 源码覆盖与用例接入 | [白盒测试设计](templates/白盒测试设计.md) |

| 节点裁决依据 | [验收报告](templates/验收报告.md) |
