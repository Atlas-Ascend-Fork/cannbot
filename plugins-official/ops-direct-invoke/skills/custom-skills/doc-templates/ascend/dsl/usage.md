# DSL 报告使用

按当前 task 及其使用的 Skill 记录报告，不增加任务、改变验收门槛或复制原始日志。DSL 节点沿用原生产物与报告契约，本实现的 templates/ 仅保留 task 按需引用的设计落稿、测试交接、性能契约与证据资料，不替代原 Skill 的业务产物格式。

规格、设计、Unit、casebook、环境 YAML、逐例结果 CSV 与性能工作流报告保留原 Skill 格式，不替换或另造 schema。执行记录与验收结论写入 task 指定位置，文件名包含完整节点 ID；业务产物仍写入原任务约定的位置。

报告引用 CODE_DIR 的完整 SHA、冻结测试及实际公开入口，区分 JIT/AOT 与环境 full/compile_only，保留 blackbox/whitebox/tdd 的 case 身份和结果。原始日志、逐例结果及版本证据独立保存，报告只给结论与路径。

区分执行者记录与验收者结论、正常/异常/跳过/未执行、局部与全量；结果须对应最终代码、测试、构建与加载身份。性能报告与结束原因由原性能工作流管理，不以报告存在证明执行或性能通过。
