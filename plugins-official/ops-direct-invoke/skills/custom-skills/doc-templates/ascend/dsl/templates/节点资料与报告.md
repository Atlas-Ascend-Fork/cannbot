# 节点的资料读取与报告

按当前 task 的职责和原有契约执行，本方法不减少应完成的调查、测试或独立验收，也不调用 PM 入口、不扩展写入或调度权限。

先定位本节点的必需输入、当前版本及已有证据索引，围绕本次要作出的决定读取相关章节、源码和原始记录。同目录下相互独立的必要读取可合并调用；避免逐行发起命令、反复通读同一资料或为报告重新打印已读取全文。没有索引时从实际输入建立本节点所需的定位依据，不把索引缺失变成额外审批或反复寻找历史报告。

直接消费已验收上游结论，按本任务要求核对存在性、版本或适用状态；不重做上游环境探测、搜索、全库调查或测试。需要引用的依据不足、有矛盾或条件变化时，再定位受影响来源；负责原始调查/环境/测试的节点仍须完成其授权工作。验收者独立阅读当前验收对象和决定结论的实际证据，不能用上游 pass、执行者摘要或“少读资料”代替本节点检查。

报告保留本节点结论、当前对象身份、原始证据路径、问题及本次变化；引用已有规格/设计条款和原始清单，不抄写整篇上游报告、重复铺陈环境表或复制同一日志/哈希清单。必要片段可引用以支持判断，原始输出与各次真实执行记录保留可读；不用模板表格数量或固定字数作验收门槛。一个事实已有有效来源时索引它，不在多个报告里独立维护多份副本。

重试先读未关闭项、实际变更和已有有效证据；只补受影响内容，报告解释不足且原始证据有效时补解释，不为更新报告重做调查或测试。版本、实际加载、适用环境或必要证据变化时仍按原任务补齐验证；缺失和失败如实记录。事实来源与结论可追溯，仍由独立验收和 harness 原生机制判定及推进。
