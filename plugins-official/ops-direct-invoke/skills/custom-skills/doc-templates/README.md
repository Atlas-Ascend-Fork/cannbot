# 文档模板

| 末级目录 | 支持 | 不支持 |
|---|---|---|
| ascend/ascendc/ | AscendC 知识、测试、检视与验收报告模板 | 推断未测范围 |
| ascend/dsl/ | DSL 原生报告格式与证据引用说明 | 替换原 Skill 的 schema |
| kirin/ascendc/ | Kirin AscendC 报告模板，区分仿真与真机证据 | 以仿真冒充真机性能 |

各实现独立维护所需说明和完整模板，不引用其他实现。AscendC 按 `$DOC_TEMPLATES_DIR/templates/` 使用本轮模板；DSL 沿用原 Skill 与任务的产物格式。
