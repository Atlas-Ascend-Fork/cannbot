# ops-registry-invoke

CANNBot 的算子开发插件。你给出一条算子需求，它自动完成需求分析、方案设计、代码
实现、测试验证与文档编写，交付一个可编译安装、在框架中以标准算子形式调用的完整
工程。

## 它能做什么

面向昇腾（Ascend）平台的算子工程师：

- **从一句话到完整交付。** 输入算子名称与功能描述，得到算子源码工程、配套测试
  与说明文档。
- **全程自动，关键处确认。** 分析、设计、编码、测试逐阶段推进，需要你拍板的
  地方会明确提示；测试全部通过才算交付。
- **自动适配硬件。** 支持 Ascend 910B 及之后的处理器，自动识别当前机器型号并
  选择对应的开发流程。
- **支持 Kirin 端侧平台开发。** 本插件**即将**支持 Kirin9030 入图算子开发，
  当前可以先使用 ops-direct-invoke 插件体验直调算子开发。

## 安装

前置条件：

- Node.js 18 及以上（需要 npx 命令）
- Git
- 已安装 CANN 环境（`asys` 命令可用）
- 一个受支持的 AI 编程工具：Claude Code、Codex、OpenCode 或 Pi

在你的工程目录执行，按提示选择你使用的工具：

```bash
npx skills add https://gitcode.com/cann/cannbot.git --skill ops-registry-invoke
```

这条命令只安装本插件本身；其余组件会在第一次使用时自动下载（需要联网，执行前
会征求你的同意），无需手动操作。之后随时可以更新到最新版本：

```bash
npx skills update
```

## 使用

1. 在装好的目录启动你的 AI 编程工具。
2. 说出算子需求，并点名使用本插件，例如："使用 ops-registry-invoke：开发算子
   AddExample：两个 float16 类型的 8×2048 张量逐元素相加，输出同形状同类型。"
3. 插件先与你确认两件事：成果放在哪个目录（默认在当前目录下新建）、用哪个工具
   执行（一般直接确认默认值即可）。
4. 之后自动开工。进度随时可查，需要决策时会来问你；全部测试通过后结束。

完成后在工作目录可以找到：算子源码工程、全部测试用例及其通过记录、算子说明
文档。

## 快速体验

安装后，把下面这段话直接发给你的 AI 编程工具：

> 使用 ops-registry-invoke：在当前机器上开发算子 AddExample——两个 float16
> 类型的 8×2048 张量逐元素相加，输出同形状同类型；要求测试全部通过，并提供能在
> PyTorch 中调用的用法。

首次运行会先自动补齐组件（需要联网与你的确认），随后开始开发。整个过程可以
旁观，也可以随时介入；结束后在工作目录查看交付的算子工程与文档。
