# pypto-op-orchestrator

`pypto-op-orchestrator` 是基于 harness 工作流的 PyPTO 算子开发与性能调优插件，
支持从算子需求出发，完成设计、实现、精度验证和性能调优。

## 功能概览

- **算子开发**：根据需求完成算子规划、实现、验证和调优。
- **性能调优**：对已完成开发和精度验证、尚待调优的算子进行性能分析、
  优化和回归验证。

单独调优时，需要保留算子开发产物和阶段记录，由 Agent 检查前置条件。

## 工作流程

完整开发流程包括七个阶段：

```text
需求规划 → Golden 生成 → 算子设计 → 验证准备
         → 算子实现 → 精度验证 → 性能调优
```

各阶段完成后进行验收。验收未通过时，工作流会按配置重试。

## 性能目标与验收

可在需求中指定性能目标和调优轮次。未指定性能目标时，不进行硬性耗时达标判断；
精度回归和产物检查仍需通过。

指定性能目标时，实测耗时达到目标即可通过性能达标检查。若已达到硬件极限，
调优报告中需提供可核实的论证，验收通过后也可结束调优。

## 快速开始

环境准备、安装命令和使用示例见 [quickstart.md](quickstart.md)。
在客户端中向 Agent 提供算子需求及相关文件，确认运行信息后即可启动工作流。
